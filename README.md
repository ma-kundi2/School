# Modern Academy Website

A professional, multi-page website for Modern Academy built with HTML, CSS, and JavaScript.

## 📋 Pages

The website includes the following pages:

1. **Home (index.html)** - Landing page with hero section, features, and highlights
2. **About (about.html)** - School mission, vision, values, history, and achievements
3. **Programs (programs.html)** - Overview of all academic programs
4. **Staff (staff.html)** - Faculty and staff directory with profiles
5. **Contact (contact.html)** - Contact information and inquiry form

## 🎨 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern Styling** - Clean and professional appearance with attractive color scheme
- **Interactive Forms** - Contact form with validation
- **Smooth Animations** - Hover effects and scroll animations for better UX
- **Navigation Menu** - Sticky navigation bar for easy access to all pages
- **Accessible Layout** - Semantic HTML for better accessibility

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/ma-kundi2/School.git
cd School
```

2. Open the website:
   - Simply open `index.html` in your web browser
   - Or use a local server for better performance

3. To use a local server (Python):
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🎯 Customization

### Update School Information
Edit the following files to customize content:
- School name and logo in the navbar
- Contact information in `contact.html`
- Staff profiles in `staff.html`
- Program details in `programs.html`
- About information in `about.html`

### Modify Colors
Update the color scheme in `css/style.css`:
- Primary color: `#3498db` (blue)
- Dark color: `#2c3e50` (dark slate)
- Background: `#f4f4f4` (light gray)

### Add More Content
Simply duplicate and modify existing cards or sections to add:
- More staff members
- Additional programs
- New features

## 🚀 Deployment

### Deploy to GitHub Pages

1. Go to repository settings
2. Navigate to "Pages" section
3. Select "main" branch as source
4. Your site will be live at: `https://ma-kundi2.github.io/School`

### Deploy to Other Hosting
- Upload files to any web hosting service
- Ensure `index.html` is the default document
- Maintain the folder structure
